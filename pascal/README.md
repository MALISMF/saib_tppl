# Pascal Interpreter

Интерпретатор для упрощенной версии языка Pascal, написанный на Rust.


Этот проект реализует интерпретатор подмножества языка Pascal, который может выполнять программы с арифметическими выражениями, переменными и вложенными блоками.


## Структура проекта

```
src/
├── lib.rs          # Главный модуль библиотеки
├── token.rs        # Определение токенов
├── lexer.rs        # Лексический анализатор
├── parser.rs       # Синтаксический анализатор
├── ast.rs          # Абстрактное синтаксическое дерево
└── interpreter.rs  # Интерпретатор
```

## Использование

### Примеры программ

#### Пример 1: Пустой блок
```pascal
BEGIN
END.
```

#### Пример 2: Арифметические выражения
```pascal
BEGIN
    x := 2 + 3 * (2 + 3);
    y := 2 / 2 - 2 + 3 * ((1 + 1) + (1 + 1));
END.
```

#### Пример 3: Вложенные блоки
```pascal
BEGIN
    y := 2;
    BEGIN
        a := 3;
        a := a;
        b := 10 + a + 10 * y / 4;
        c := a - b
    END;
    x := 11;
END.
```


```bash

```

```bash

cargo build --release
```
