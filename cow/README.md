# Интерпретатор языка COW

Этот проект реализует полнофункциональный интерпретатор для языка COW. Интерпретатор поддерживает все основные команды языка, включая работу с памятью, циклами, вводом/выводом и регистром.

## Установка

### Требования

- Rust 1.70 или новее
- Cargo (менеджер пакетов Rust)

### Сборка проекта

```bash
# Соберите проект
cargo build --release

# Или соберите и запустите сразу
cargo run --release
```

## Использование

### Запуск примера

В файле `src/main.rs` уже есть пример программы. Запустите его:

```bash
cargo run
```

## Команды языка COW

| Команда | Описание |
|---------|----------|
| `MoO` | Увеличивает значение текущей ячейки на 1 |
| `MOo` | Уменьшает значение текущей ячейки на 1 |
| `moO` | Перемещает указатель вправо (увеличивает адрес) |
| `mOo` | Перемещает указатель влево (уменьшает адрес) |
| `MOO` | Начало цикла: если текущая ячейка = 0, переходит к соответствующему `moo` |
| `moo` | Конец цикла: если текущая ячейка ≠ 0, возвращается к соответствующему `MOO` |
| `OOM` | Выводит числовое значение текущей ячейки |
| `oom` | Читает число из стандартного ввода и записывает в текущую ячейку |
| `mOO` | Выполнение инструкции по значению текущей ячейки (не реализовано) |
| `Moo` | Условный ввод/вывод: если ячейка = 0, читает число, иначе выводит символ |
| `OOO` | Обнуляет текущую ячейку |
| `MMM` | Работа с регистром: сохраняет/восстанавливает значение |

## Примеры программ

### Пример 1: Вывод чисел

```cow
MoO MoO MoO OOM    # Увеличить на 3 и вывести (выведет: 3)
```

### Пример 2: Простой цикл

```cow
MoO MoO MoO        # Установить значение 3
MOO                 # Начало цикла
MOo OOM            # Уменьшить и вывести
moo                 # Конец цикла (пока значение не станет 0)
```

### Пример 3: Ввод и вывод

```cow
oom                # Ввести число
MoO MoO            # Увеличить на 2
OOM                # Вывести результат
```

### Пример 4: Работа с регистром

```cow
MoO MoO MoO        # Установить значение 3
MMM                # Сохранить в регистр
OOO                # Обнулить ячейку
MMM                # Восстановить из регистра
OOM                # Вывести (выведет: 3)
```

## Архитектура

Интерпретатор состоит из следующих основных компонентов:

- **Структура `Cow`**: Хранит состояние интерпретатора
  - `cells`: HashMap для хранения ячеек памяти
  - `current`: Текущая позиция указателя
  - `register`: Регистр для временного хранения
  - `ip`: Индекс текущей инструкции
  - `instructions`: Список всех инструкций программы
  - `loop_map`: Карта соответствий между началом и концом циклов

- **Методы**:
  - `new()`: Создание нового интерпретатора из исходного кода
  - `build_loop_map()`: Построение карты циклов для быстрого перехода
  - `run()`: Запуск выполнения программы
  - `moo_cmd*()`: Реализация отдельных команд языка
